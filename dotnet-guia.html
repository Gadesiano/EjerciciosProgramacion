01

Modificadores de acceso

Determinan desde dónde es accesible una clase, método o propiedad. Controlan la visibilidad de los elementos del código.

Modificador Accesible desde...
public Cualquier parte del código, dentro y fuera del proyecto.
internal Solo dentro del mismo proyecto (ensamblado). Valor por defecto en clases generadas por Visual Studio. default
private Solo dentro de la propia clase. En clases de nivel superior no tiene sentido; se usa en clases anidadas.
protected Dentro de la clase y sus clases derivadas (herencia). Solo aplica a clases anidadas.
protected internal Combinación: accesible desde el mismo ensamblado O desde clases derivadas en otros ensamblados. avanzado
private protected Combinación restrictiva: solo desde clases derivadas dentro del mismo ensamblado. avanzado 
public class MiClase           // Accesible desde cualquier sitio
internal class MiClase        // Solo dentro del proyecto
private class MiClaseAnidada  // Solo dentro de la clase contenedora
💡 Regla práctica en este proyecto: las clases de ejercicios van en public porque Program.cs las instancia desde fuera de su namespace.
02

Tipos de datos primitivos

Los tipos primitivos son los bloques básicos de datos del lenguaje. En C# todos son alias de tipos del sistema .NET.

Tipo C# Tipo .NET Descripción Ejemplo
int Int32 Entero de 32 bits. Rango: −2.147M a 2.147M int x = 42;
long Int64 Entero de 64 bits. Para valores muy grandes. long x = 9999999999L;
double Double Número decimal de doble precisión. double x = 3.14;
float Single Decimal de simple precisión. Menos exacto que double. float x = 3.14f;
decimal Decimal Alta precisión decimal. Usado en cálculos financieros. decimal x = 9.99m;
bool Boolean Verdadero o falso. bool x = true;
char Char Un único carácter Unicode. Se define con comillas simples. char x = 'A';
string String Cadena de texto. Aunque no es estrictamente primitivo, se trata como tal en C#. string x = "Hola";
object Object Tipo base del que derivan todos los tipos en .NET. object x = 42; 
int     entero   = 42;
double  decimal_ = 3.14;
bool    activo   = true;
char    letra    = 'A';
string  nombre   = "C#";
03

Variables y constantes

Una variable es un espacio en memoria con nombre cuyo valor puede cambiar. Una constante se define una vez y no puede modificarse.

// Variable — se puede reasignar
string lenguaje = "C#";
lenguaje = "Python";   // válido

// Constante — valor fijo en tiempo de compilación
const string URL = "https://dotnet.microsoft.com";
URL = "otra";           // ERROR: no se puede reasignar

// var — el compilador infiere el tipo automáticamente
var numero = 42;         // el compilador lo trata como int
var texto  = "Hola";     // el compilador lo trata como string
⚠️ var no es un tipo dinámico — el tipo se determina en compilación y no puede cambiar. Es solo azúcar sintáctico para no repetir el tipo cuando ya es obvio por el valor asignado.
04

Comentarios

Los comentarios son ignorados por el compilador. Sirven para documentar el código o desactivar líneas temporalmente.

// Comentario de una sola línea

/*
 * Comentario de
 * varias líneas
 */

/// <summary>
/// Comentario XML de documentación.
/// Visual Studio lo muestra como tooltip al usar la clase o método.
/// </summary>
public void MiMetodo() { }
💡 Los comentarios /// (triple barra) generan documentación automática que Visual Studio muestra como tooltip. Es buena práctica usarlos en interfaces y métodos públicos.
05

Interfaces

Una interfaz es un contrato. Define qué debe poder hacer una clase, pero no cómo lo hace. Cualquier clase que implemente la interfaz está obligada a implementar todos sus miembros.

En C# una interfaz puede declarar métodos, propiedades, eventos e indexadores — pero no campos ni implementaciones (salvo implementaciones por defecto en C# 8+).

// Definición de la interfaz
public interface IEjercicio
{
    string Titulo { get; }   // propiedad de solo lectura
    void Run();               // método sin implementación
}

// Clase que implementa la interfaz
public class Ejercicio00 : IEjercicio
{
    public string Titulo => "#00 - Hola Mundo";

    public void Run()
    {
        Console.WriteLine("¡Hola, C#!");
    }
}

// Uso polimórfico: Program.cs no sabe qué ejercicio es, solo que tiene Run()
IEjercicio ejercicio = new Ejercicio00();
ejercicio.Run();
💡 Convención de nombres: las interfaces en C# siempre empiezan por I mayúscula. Es una convención tan fuerte que el propio Visual Studio la aplica por defecto al crear una interfaz.
⚠️ Una clase puede implementar múltiples interfaces a la vez, pero solo puede heredar de una única clase base. Esto hace que las interfaces sean la herramienta principal para lograr polimorfismo flexible en C#.
